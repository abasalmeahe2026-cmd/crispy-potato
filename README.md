# crispy-potato
منصة OSINT العراق مركز عربي للرصد والتحليل الاستخباراتي مفتوح المصدر، متخصص بمتابعة الأحداث الأمنية والعسكرية والسياسية في العراق والمنطقة، والتحقق من الأخبار والصور والفيديوهات، وإعداد تقارير تحليلية موثوقة، مع توثيق الأحداث زمنياً والتمييز بين الحقائق والادعاءات والتقديرات باستخدام الذكاء الاصطناعي.  الحقيقة أولاً، والمعلومة بالدليل.
